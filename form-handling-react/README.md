# Form Handling in React

A React application demonstrating form handling using controlled components and Formik.

## Features

- **Controlled Components**: Manual form state management with useState
- **Formik + Yup**: Advanced form handling with schema validation

## Setup
```bash
npm install
npm run dev
```

## Components

- `RegistrationForm.jsx` - Controlled components form
- `formikForm.js` - Formik form with Yup validation
