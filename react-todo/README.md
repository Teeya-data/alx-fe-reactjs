# React Todo App

A fully functional Todo List application with comprehensive tests.

## Features

- ✅ Add new todos
- ✅ Toggle todo completion status
- ✅ Delete todos
- ✅ Comprehensive Jest tests

## Setup
```bash
npm install
```

## Run the App
```bash
npm run dev
```

## Run Tests
```bash
npm test
```

## Tests Included

- Component rendering test
- Initial todos display test
- Add todo functionality test
- Toggle todo completion test
- Delete todo test

## Technologies

- React
- Vite
- Jest
- React Testing Library
