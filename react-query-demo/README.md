# React Query Demo

Advanced data handling with React Query (TanStack Query).

## Features

- Data fetching from JSONPlaceholder API
- Automatic caching and background updates
- Loading and error states
- Manual refetch capability
- React Query DevTools integration

## Setup
```bash
npm install
npm run dev
```

## React Query Features Demonstrated

- **Caching**: Data cached for 5 minutes
- **Stale Time**: Fresh for 60 seconds
- **Refetching**: Manual refetch button
- **Component Mount/Unmount**: Cache persists
- **DevTools**: Inspect cache and queries

## API

Uses JSONPlaceholder: https://jsonplaceholder.typicode.com/posts
